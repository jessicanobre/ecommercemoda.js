## Manual de Uso - Sistema de Controle de Vendas e Estoque
Introdução

Este sistema permite simular vendas, atualizar o estoque de produtos e monitorar o nível de estoque baixo. A API foi desenvolvida em Node.js e oferece endpoints para gerenciamento de estoque.

Pré-requisitos

Antes de começar, certifique-se de ter instalado:

Node.js (versão 14 ou superior)
npm (gerenciador de pacotes do Node.js)
